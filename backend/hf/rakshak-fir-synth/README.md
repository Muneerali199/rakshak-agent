# RAKSHAK FIR synthetic bench (rakshak-fir-synth)

Synthetic FIR dataset generated by the RAKSHAK simulator (`synthgen/`) for the
24-hour hackathon fine-tune. It is **synthetic**, contains **no real people or
cases**, and is used to train an Indic NER entity tagger (Option B).

## Structure

Four JSON-line streams with the exact schema the trainer consumes:

- `fir.jsonl` — one per FIR: record_id, district, police_station, date,
  ipc_sections, complainant {name,age,address}, accused[{name,address}],
  narrative (English / code-mix / Devanagari).
- `mentions.jsonl` — per-entity ground truth: record_id, entity_type
  (PERSON|PHONE|ACCOUNT|VEHICLE|LOCATION|AMOUNT|...), surface, true_id,
  field (complainant|accused|narrative|...). This is the BIO-labelling source.
- `cdr.jsonl` / `fin.jsonl` — call and financial-transfer records used to build
  the identity graph and cross-case edges (not needed for NER training).

## Verified-audit notes

- Duplicates removed by record_id / mention_id across output + output-vaults.
- PERSON surfaces are already mixed-script (Devanagari + Latin variants) by the
  generator — exactly the code-mix the regex extractor cannot handle.
- NO real data: all names/phones/accounts/plates are from synthgen pools.

## Use

Train the NER from `mentions.jsonl` + `fir.jsonl` (see
[IND_NER_FINETUNE_PLAN.md](../../docs/IND_NER_FINETUNE_PLAN.md)). If you need
the *other* RAKSHAK datasets (code-security/CWE SFT), see
`../../docs/huggingface/DATASETS.md` — those are a different domain and are the
wrong training signal for FIR entity extraction.
